# 🏫 Smart Campus Announcement System

## 📌 Project Overview

The **Smart Campus Announcement System** is a web-based application designed to provide students and faculty with quick access to important campus announcements and notices. Users can view, search, filter, and publish announcements through a simple and interactive interface.

The project is developed using **HTML, CSS, and JavaScript**. It runs directly in a web browser using VS Code and Live Server, without requiring Firebase or a database.

## 🎯 Objective

The main objective of this project is to create a centralized platform for sharing important campus information such as academic notices, examination updates, events, library information, transport updates, and general announcements.

## ✨ Features

* 📢 Display campus announcements
* 🔎 Search announcements
* 🏷️ Filter announcements by category
* 📅 Display announcement dates
* ⭐ Highlight important notices
* ➕ Add new announcements
* 🌙 Dark mode
* 📊 Announcement statistics
* 📱 Responsive design
* ⚡ Interactive JavaScript functionality
* 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used

* **HTML5** – Creates the structure of the application
* **CSS3** – Provides styling, layout, and responsive design
* **JavaScript** – Handles search, filtering, adding announcements, and dark mode
* **VS Code** – Development environment
* **Live Server** – Runs the project locally

## 🚀 How to Run the Project

### Step 1: Download the Project

Download or clone this repository to your computer.

### Step 2: Open the Project

Open the project folder using **Visual Studio Code**.

### Step 3: Check the Files

Make sure the following files are available:

```text
index.html
style.css
script.js
README.md
```

### Step 4: Install Live Server

In VS Code:

1. Open **Extensions**
2. Search for **Live Server**
3. Install the extension

### Step 5: Run the Website

Open `index.html`.

Right-click inside the file and select:

```text
Open with Live Server
```

The Smart Campus Announcement System will open in your default browser.

## 📋 Main Modules

### 1. Home

Provides an introduction to the Smart Campus Announcement System and quick access to campus notices.

### 2. Announcement Management

Displays important announcements related to academics, examinations, events, library services, transport, and general campus activities.

### 3. Search

Users can search for announcements by entering keywords in the search box.

### 4. Category Filter

Announcements can be filtered into categories such as:

* Academic
* Events
* Examination
* General

### 5. Add Announcement

Users can enter a title, description, and category to publish a new announcement on the page.

### 6. Dark Mode

Users can switch between light and dark themes.

### 7. Responsive Design

The system adapts to desktop, tablet, and mobile screen sizes.
